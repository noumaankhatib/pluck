# Pluck.media website

Next.js App Router site. Homepage is the current design benchmark.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Blueprint: [`../docs/IMPLEMENTATION_BLUEPRINT.md`](../docs/IMPLEMENTATION_BLUEPRINT.md)

Creative rulebook: [`../docs/PLUCK_CREATIVE_RULEBOOK.md`](../docs/PLUCK_CREATIVE_RULEBOOK.md) — positioning, voice, visual mood, and pre-flight checklist.

Vector master (logo, colours, fonts): [`../docs/PLUCK_VECTOR_MASTER.md`](../docs/PLUCK_VECTOR_MASTER.md). Drop SVG/PNG into `public/brand/`.

Copy lives in `src/content/`. Replace when master content assets are added to the repo.

Cursor rules in `.cursor/rules/` distill the rulebook for AI-assisted edits (`pluck-creative-brief.mdc` always applies).
